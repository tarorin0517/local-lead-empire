# 香美市の空き家管理はいつ始めるべき？——台風シーズン前が分岐点

「香美市の空き家管理を始めたいが、いつから動くべきか？」——太平洋側気候の香美市では、本州内陸部や日本海側の市町とは異なる「始めどき」があります。本コラムでは、相続発生からの時系列・季節要因・地区別の地形条件を踏まえた4つの分岐点を整理します。

## タイミング1：相続発生直後（四十九日〜半年以内）

最も推奨されるのが相続直後のスタートです。

### 香美市で相続直後の対応が特に重要な理由

香美市は太平洋側多雨気候で、年間2,500mm超の降雨が建物を継続的に攻撃します。相続によって空き家となった建物は、それ以前に既に半年〜数年の無人状態が続いていることが多く、見た目は問題なくても床下・天井裏で湿気被害が進行している可能性が高い地域です。

特に楠目・大栃などの山間部、土佐山田旧街道沿いの古民家では、土壁・床下のカビ進行が市街地より速く、相続から1年放置すると修繕コストが2〜3倍に跳ね上がる事例が多くあります。相続直後にベースライン（現状記録）を作っておくことが、その後の管理計画の基礎になります。

### 相続直後にやるべきこと（香美市版）

- 物件の現況写真撮影（外観・内部・屋根・床下・敷地）
- 香美市役所への登記変更確認（土地・建物名義）
- 残置物の確認と整理計画（古文書・農具・ゆず関連器具は別途査定推奨）
- 鍵の所在確認・スペアキーの管理
- 固定資産税納税通知書の所在確認
- 近隣・町内会・集落営農協定への挨拶
- 農地一体型物件の場合、農業委員会への相続届出
- 電気・水道・ガスの基本契約継続判断

「四十九日が終わってから動こう」と先送りすると、梅雨・台風・冬の凍結のいずれかが建物に深刻な影響を及ぼします。

## タイミング2：遠方移住・住み替え前（引越し直前）

香美市は高知龍馬空港から車で30分、関西・関東からのアクセスは限定的です。移住前に管理体制を整えておくことが重要です。

### 移住後のアクセス困難の現実

- 関東（東京・横浜）から香美市：飛行機＋レンタカーで5〜6時間
- 関西（大阪・神戸）から香美市：新幹線＋車で5〜6時間
- 九州（福岡）から香美市：車またはフェリー＋車で6〜7時間
- 高知市内から香美市：車で40〜50分

「気になったら見に行く」が現実的に困難なため、**移住前の管理契約は強く推奨**です。

### 移住前準備のチェックリスト

| 準備項目 | 対応の目安 |
|---------|----------|
| 定期巡回業者との契約 | 移住の1〜2ヶ月前まで |
| 郵便物の転送・受取設定 | 引越し1週間前まで |
| 近隣・町内会・集落営農協定への挨拶 | 引越し直前 |
| 電気・水道の最低契約継続 | 引越し時点で判断 |
| 鍵の管理方法決定 | 業者契約と同時に決定 |
| 農業委員会への届出 | 農地一体型物件のみ |

## タイミング3：梅雨入り前（5月下旬〜6月初旬）

すでに空き家として放置されている物件の場合、梅雨前が次のベストタイミングです。

### 香美市の梅雨の特徴

香美市の梅雨期間は6〜7月で、年間降水量約2,500mmのうち約4割がこの時期に集中します。太平洋側で線状降水帯の通過頻度が高く、短時間に200mm超の集中豪雨も発生します。

換気されていない空き家では、梅雨入り直後から内部湿度が80〜90%に達し、押し入れ・床下・畳の急速なカビ発生を招きます。山間部（大栃・楠目）では、霧の発生頻度が高く市街地より湿度が常時5〜10%高いため、梅雨入り前の対応がより重要です。

### 梅雨前に実施すべきこと

- 雨樋・縦樋の落ち葉除去
- 床下換気口の詰まり確認
- 押し入れ・収納の換気と防カビ剤設置（倍量）
- 窓開け換気（最低2時間）
- 草刈り（伸びる前の予防的施工）
- 屋根瓦の点検（梅雨での雨漏り防止）
- 物部川河岸物件の床下浸水対策

## タイミング4：台風シーズン前（7月下旬）★香美市特有

香美市の管理タイミングで最も特徴的なのが**台風シーズン前**です。

### 香美市の台風事情

- 太平洋側のため台風直撃の頻度が高い（年に複数回）
- 8〜10月が台風シーズンのピーク
- 線状降水帯の通過頻度も高い
- 物部川流域は河川増水・床下浸水リスク
- 山間部（大栃・別府峡）は土砂崩れ・道路寸断リスク
- 海岸からは離れているが暴風被害は深刻

### 台風シーズン前の必須対応

7月下旬までに以下を完了させておくことが、台風被害を最小化します：

- 屋根瓦のズレ・破損の事前点検と修繕
- 雨樋・縦樋の補強と落ち葉除去
- 雨戸・サッシの固定確認
- 敷地内の倒木・落枝リスク確認（楠目・大栃は特に重要）
- 物干し竿・植木鉢など飛散リスクのある物の整理
- ブルーシート・養生資材の事前準備

**7月下旬を逃すと、8月の台風直前に駆け込み対応となり、業者も予約が埋まります**。事前対応が圧倒的に有利です。

## 放置期間別のリスク早見表（香美市版）

| 放置期間 | 発生しやすい劣化 | 修繕コスト目安 |
|---------|----------------|--------------|
| 〜半年 | 押し入れのカビ・郵便物滞留 | 数千円〜2万円 |
| 半年〜1年 | 雨樋詰まり・床下湿気・畳の腐食 | 5〜25万円 |
| 1〜3年 | 雨漏り・シロアリ被害・台風被害の蓄積 | 50〜150万円 |
| 3〜5年 | 構造材の腐食・屋根損傷・獣害侵入 | 150〜400万円 |
| 5年〜 | 倒壊リスク・特定空家指定 | 解体300〜600万円 |

多雨・台風が複合する香美市は、同じ放置期間でも内陸都市より修繕コストが高めになります。

## まちのプロでは

香美市内の空き家管理を月額5,000円〜の定期巡回プランで承っています。相続直後の現地確認（無料）・移住前の管理プラン設計・台風シーズン前の総合点検まで、タイミングに応じた柔軟な対応が可能です。大栃・別府峡など山間部の物件も対応します。お電話でご相談ください。
