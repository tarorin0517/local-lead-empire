# 萩市の空き家管理はいつ始めるべき？——冬の雪害シーズン前が分岐点

「萩市の空き家管理を始めたいが、いつから動くべきか？」——日本海側気候の萩市では、本州瀬戸内側の市町とは異なる「始めどき」があります。本コラムでは、相続発生からの時系列・季節要因・地区別の地形条件を踏まえた4つの分岐点を整理します。

## タイミング1：相続発生直後（四十九日〜半年以内）

最も推奨されるのが相続直後のスタートです。

### 萩市で相続直後の対応が特に重要な理由

萩市は山口県北部に位置し、夏の湿気と冬の積雪が交互に建物を傷める気候です。相続によって空き家となった建物は、それ以前に既に半年〜数年の無人状態が続いていることが多く、見た目は問題なくても床下・天井裏で湿気被害が進行している可能性があります。

特に椿東・浜崎・堀内などの古い武家屋敷町では、土壁・漆喰の劣化、瓦のズレが内部にまで進んでいる事例が多く見られます。相続直後にベースライン（現状記録）を作っておくことが、その後の管理計画の基礎になります。

### 相続直後にやるべきこと（萩市版）

- 物件の現況写真撮影（外観・内部・屋根回り）
- 萩市まちじゅう博物館推進課への景観計画区域該当確認（重点景観計画区域の場合）
- 残置物の確認と整理計画（萩焼の食器類は別途査定推奨）
- 鍵の所在確認・スペアキーの管理
- 固定資産税納税通知書の所在確認
- 近隣・町内会への挨拶
- 電気・水道・ガスの基本契約継続判断

「四十九日が終わってから動こう」と先送りすると、夏の湿気か冬の雪害のいずれかが建物に深刻な影響を及ぼします。相続が分かった時点で、まずは現地確認だけでも実施することを強くお勧めします。

## タイミング2：遠方移住・住み替え前（引越し直前）

萩市は高速道路から距離があり、関東・関西・九州中心部からのアクセスに時間を要します。移住前に管理体制を整えておくことが他県より重要です。

### 移住後のアクセス困難の現実

- 関東（東京・横浜）から萩市：飛行機＋レンタカーで5〜7時間
- 関西（大阪・神戸）から萩市：新幹線＋車で5〜6時間
- 九州（福岡・北九州）から萩市：車で2.5〜3時間
- 山口県内（山口市・宇部）から：車で1〜1.5時間

「気になったら見に行く」が現実的に困難なため、**移住前の管理契約は必須レベル**です。

### 移住前準備のチェックリスト

| 準備項目 | 対応の目安 |
|---------|----------|
| 定期巡回業者との契約 | 移住の1〜2ヶ月前まで |
| 郵便物の転送・受取設定 | 引越し1週間前まで |
| 近隣・町内会への挨拶 | 引越し直前 |
| 電気・水道の最低契約継続 | 引越し時点で判断 |
| 鍵の管理方法決定 | 業者契約と同時に決定 |
| 萩市の景観条例該当確認 | 重点景観計画区域の場合のみ |

## タイミング3：梅雨入り前（5月下旬〜6月初旬）

すでに空き家として放置されている物件の場合、梅雨前が次のベストタイミングです。

### 萩市の梅雨の特徴

萩市の梅雨期間は6〜7月で、年間降水量約1,900mmのうち約3割がこの時期に降ります。日本海側気候のため、梅雨明けが遅く（7月下旬〜8月初旬）、降雨期間が長引く傾向があります。

換気されていない空き家では、梅雨入り直後から内部湿度が80〜90%に達し、押し入れ・床下・畳の急速なカビ発生を招きます。古い町家・武家屋敷では、土壁の吸湿性を超えた湿度がかかると、内部の木舞・竹小舞が腐朽するリスクがあります。

### 梅雨前に実施すべきこと

- 雨樋・縦樋の落ち葉除去
- 床下換気口の詰まり確認
- 押し入れ・収納の換気と防カビ剤設置
- 窓開け換気（最低2時間）
- 草刈り（伸びる前の予防的施工）
- 土壁・漆喰の状態確認（古民家の場合）

## タイミング4：冬の雪害シーズン前（11月初旬）★萩市特有

萩市の管理タイミングで最も特徴的なのが**冬の雪害シーズン前**です。

### 萩市の冬の気象条件

- 冬の北西季節風（11〜3月）が日本海から直接吹き付ける
- 平地で年数回の積雪（10〜20cm）、山間部（旭・川上・福栄）では50cm超になる年も
- 海岸部（越ヶ浜・須佐・三見）では強い塩風＋強風による外壁・サッシ被害
- 凍結による水道管破裂リスク

### 雪害シーズン前の必須対応

11月初旬までに以下を完了させておくことが、冬の被害を最小化します：

- 屋根瓦のズレ・破損の事前点検と修繕
- 雨樋・縦樋の補強と落ち葉除去
- 雨戸・サッシの固定確認
- 水道メーター周辺・露出配管の凍結防止材巻き付け
- 雪下ろし業者との事前契約（山間部・須佐の物件）
- 敷地内の倒木リスク確認

**11月初旬を逃すと、12月以降の積雪期間に作業が困難になり、被害発生後の対応となります**。雪害は瓦の飛散→雨漏り→構造材腐食という連鎖を生むため、事前対応が圧倒的に有利です。

## 放置期間別のリスク早見表（萩市版）

| 放置期間 | 発生しやすい劣化 | 修繕コスト目安 |
|---------|----------------|--------------|
| 〜半年 | 押し入れのカビ・郵便物滞留 | 数千円〜2万円 |
| 半年〜1年 | 雨樋詰まり・床下湿気・畳の腐食 | 5〜25万円 |
| 1〜3年 | 雨漏り・シロアリ被害・冬の雪害蓄積 | 40〜120万円 |
| 3〜5年 | 構造材の腐食・屋根損傷・塩害サッシ破損 | 120〜400万円 |
| 5年〜 | 倒壊リスク・特定空家指定 | 解体300〜600万円 |

塩害・雪害が複合する萩市は、同じ放置期間でも内陸都市より修繕コストが高めになる傾向があります。

## まちのプロでは

萩市内の空き家管理を月額5,000円〜の定期巡回プランで承っています。相続直後の現地確認（無料）・移住前の管理プラン設計・雪害シーズン前の総合点検まで、タイミングに応じた柔軟な対応が可能です。須佐エリア・山間部の物件も対応します。お電話でご相談ください。
