# 宇佐市の空き家管理はいつ始めるべき？——相続直後・移住前が分岐点

「空き家になったけど、いつから管理を始めればよいのか？」——宇佐市の空き家所有者の方から最も多くいただく質問です。結論から言うと、**空き家になった瞬間が最も適切なタイミング**です。放置期間が長くなるほど、建物の劣化が加速し、管理コストよりも修繕コストが上回ってしまいます。本コラムでは、宇佐市の気候・行政事情を踏まえた4つの「始めどき」を整理します。

## タイミング1：相続発生直後（四十九日〜半年以内）

最も推奨されるのが相続発生直後のスタートです。

### なぜ相続直後が重要か

相続によって空き家となった建物は、それ以前の生活状況によって状態が大きく異なります。亡くなった方が一人暮らしで施設・病院に入っていた場合、すでに半年〜数年の無人状態が続いている可能性が高く、見た目には問題なくても床下・屋根裏に湿気・カビ・シロアリ被害が進行しています。**相続直後に現状を確認しておくことで、劣化のベースライン（基準点）を記録できる**のが最大のメリットです。

### 相続直後にやるべきこと

- 物件の現況写真撮影（外観・内部・敷地）
- 残置物の確認と整理計画
- 鍵の所在確認・スペアキーの管理
- 固定資産税納税通知書の所在確認
- 近隣への挨拶（連絡先の交換）
- 電気・水道・ガスの基本契約継続判断

**「四十九日が終わってから動こう」と先送りすると、梅雨や台風で建物が大きく傷むリスクがあります**。宇佐市の気候では半年放置するだけで、床下のカビ・畳の腐食・押し入れの黒カビが顕在化します。相続が分かった時点で、まずは現地確認だけでも実施することを強くお勧めします。

## タイミング2：遠方移住・住み替え前（引越し直前）

オーナー様自身が宇佐市から県外・市外に移住する場合、移住前に管理体制を整えておくことが極めて重要です。

### 移住後に発生する典型的なトラブル

- 「気になったときに見に来れない」状態が長期化
- 郵便物が溜まり、重要書類（行政文書・固定資産税通知）の見落とし
- 近隣からの苦情を直接受けられない
- 緊急時（台風・地震後）に建物状況が分からない

**移住前に「鍵の管理」「郵便物転送」「定期巡回契約」「緊急時の連絡先設定」の4点を整えておく**だけで、その後のトラブル発生率が大きく下がります。

### 移住前準備のチェックリスト

| 準備項目 | 対応の目安 |
|---------|----------|
| 定期巡回業者との契約 | 移住の1〜2ヶ月前まで |
| 郵便物の転送・受取設定 | 引越し1週間前まで |
| 近隣への挨拶と連絡先共有 | 引越し直前 |
| 電気・水道の最低契約継続 | 引越し時点で判断 |
| 鍵の管理方法決定 | 業者契約と同時に決定 |

## タイミング3：梅雨入り前（5〜6月初旬）

すでに空き家として放置されている物件の場合、梅雨入り前が次のベストタイミングです。

### 宇佐市の梅雨と空き家リスク

宇佐市は梅雨期間（6〜7月）に集中して降水量が増え、年間降水量の約3割がこの時期に降ります。換気されていない空き家では、梅雨入り直後から内部湿度が80〜90%に達し、押し入れ・床下・畳の急速なカビ発生を招きます。

**梅雨前に1回でも換気・点検を入れておく**ことで、梅雨期間の被害を大きく抑えられます。

### 梅雨前に実施すべきこと

- 雨樋・縦樋の落ち葉除去（雨水のオーバーフロー防止）
- 床下換気口の詰まり確認
- 押し入れ・収納の換気と防カビ剤設置
- 窓開け換気（最低2時間）
- 草刈り（伸びる前の予防的施工）

## タイミング4：台風シーズン前（8月初旬）

宇佐市は周防灘に面し、毎年複数の台風が接近します。台風前の事前点検を入れておくことで、被害の最小化が可能です。

### 台風被害の典型パターン

- 屋根瓦のズレ・飛散
- 雨戸・サッシの破損
- 雨樋の脱落
- 敷地内の倒木・物置の倒壊
- 高潮による沿岸部物件への浸水（柳ヶ浦・長洲エリア）

**台風前の事前確認で雨戸を閉鎖し、飛散しやすい物を撤去するだけで、被害額が10分の1以下になることもあります**。台風通過後の緊急点検も重要で、被害を早期発見すれば応急処置で雨漏りの拡大を防げます。

## 放置期間別のリスク早見表

| 放置期間 | 発生しやすい劣化 | 修繕コスト目安 |
|---------|----------------|--------------|
| 〜半年 | 押し入れのカビ・郵便物滞留 | 数千円〜2万円 |
| 半年〜1年 | 雨樋詰まり・床下湿気・畳の腐食 | 5〜20万円 |
| 1〜3年 | 雨漏り・シロアリ被害・外壁劣化 | 30〜100万円 |
| 3〜5年 | 構造材の腐食・屋根損傷 | 100〜300万円 |
| 5年〜 | 倒壊リスク・特定空家指定 | 解体300〜500万円 |
