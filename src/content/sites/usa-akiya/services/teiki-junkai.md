# 宇佐市の空き家定期巡回点検サービス

「相続した実家が宇佐市にあるが、遠方で管理できない」「台風や大雨の後に建物が傷んでいないか心配」——そんなオーナー様の代わりに、専門スタッフが定期的に宇佐市内の空き家を巡回点検します。巡回後は写真付きのレポートをメールでお届けするため、現地に出向かなくても建物の状態をリアルタイムで把握できます。

## サービス内容

**基本巡回（毎回実施）**
- 外観確認：屋根・外壁・雨樋・基礎の目視チェック。亀裂・損傷・腐食・カビの発生を確認します
- 換気：主要な部屋の窓・通気口を開けての換気実施（30分程度）。宇佐市の多湿な気候では換気が建物保護の要です
- 郵便物整理：投函された郵便物・チラシを整理し、重要そうな書類はご報告します
- 敷地確認：不法投棄・不審者侵入の痕跡・フェンスの損傷・排水口の詰まりを確認します
- 雨樋・排水チェック：梅雨・台風シーズンに詰まりやすい雨樋・縦樋の状態を確認します

**写真付きレポート**
巡回のたびに外観・内部の主要箇所を写真撮影し、確認事項・問題点・推奨対応をまとめたレポートをメールでお送りします。問題がない場合も「異常なし」の確認レポートをお届けしますので、遠方にいながら安心して管理をお任せいただけます。

**緊急時対応**
台風接近・大雨・地震など異常気象の後は、契約物件を優先確認します。問題を発見した場合は電話で即時ご連絡し、対応方針を協議します。

## 宇佐市の気候・地域特性に対応した点検

### 宇佐神宮周辺の古民家対応

宇佐神宮の門前町・参道周辺には木造の古民家が多く残っています。これらの建物は気密性が低く、温暖多湿の宇佐市の気候では湿気が建物内部に溜まりやすい構造です。長期間換気が行われないと、押し入れや床下にカビが大量発生し、構造材の腐食が急速に進みます。定期巡回では、こうした古民家特有のリスクポイントを重点的に確認します。

### 院内・安心院の山間部物件への対応

宇佐市北部の院内・安心院エリアは山間部のため、以下のリスクが市街地より高くなります。

- **土砂・落葉の堆積**：傾斜地に建つ物件では雨樋に落ち葉・土砂が詰まりやすく、雨水のオーバーフローが外壁・基礎を傷めます
- **獣害**：山間部ではイノシシ・タヌキなどによる敷地侵入・床下侵入のリスクがあります。痕跡を早期発見し対応します
- **冬季の凍結**：院内・安心院は市街地より気温が低く、冬季には水道管凍結のリスクがあります。巡回時に水道元栓の状態も確認します
- **道路アクセス**：大雨・台風後の土砂崩れ・倒木で道路状況が変化することがあります。現地状況を随時確認し、異常時は即報告します

### 温暖多湿な宇佐市の気候対策

宇佐市の年間降水量は約1,800〜2,000mmで、梅雨から台風シーズン（6〜10月）に集中します。温暖多湿の環境では、空き家内部の湿度が長期間高い状態が続くと：

1. 木材腐朽菌の繁殖による柱・梁の腐食
2. シロアリ被害（高湿度はシロアリが好む環境）
3. 結露による壁内部の断熱材・木材の湿潤劣化

が進行します。定期巡回での換気実施と湿度管理は、こうした被害を最小限に抑えるための最重要対策です。

## 巡回チェック項目（詳細）

各巡回で確認する主な項目は以下の通りです：

| チェックカテゴリ | 確認内容 |
|----------------|---------|
| 屋根・雨樋 | 瓦のズレ・割れ、雨樋の詰まり・破損、棟板金の浮き |
| 外壁 | ひび割れ、塗装の剥がれ、カビ・コケの発生、シーリングの劣化 |
| 基礎 | ひび割れ、土台の腐食、床下換気口の詰まり |
| 内部 | カビの発生、雨漏りの痕跡、押し入れ・収納の湿気状態 |
| 敷地 | 草の繁茂状況、不法投棄、フェンス・門扉の損傷 |
| 設備 | 水道元栓の状態、エアコン室外機の状態、電気メーターの異常 |
| 郵便物 | 投函物の整理・分類、重要書類の報告 |

## よくあるご質問（定期巡回）

**Q. 宇佐神宮周辺の古民家ですが、点検してもらえますか？**
A. はい。宇佐神宮周辺の古民家にも対応しています。木造古民家特有の湿気・換気リスクを踏まえた点検を行います。

**Q. 院内・安心院の山間部の物件でも対応できますか？**
A. 対応しています。山間部は道路状況・アクセス条件により料金が変わる場合があります。現地確認時に詳細をご案内します。

**Q. 台風が近づいているが、事前に確認してもらえますか？**
A. 台風接近前の事前確認にも対応しています。定期管理契約いただいているお客様は優先対応いたします。

**Q. 鍵の管理はどうなりますか？**
A. 合鍵をお預かりするか、キーボックスを設置していただく方法で対応します。鍵の管理については契約時に詳細を取り決めます。

**Q. 毎回同じ担当者が来ますか？**
A. 原則として担当者を固定し、物件の特性・変化を継続的に把握できる体制をとっています。
