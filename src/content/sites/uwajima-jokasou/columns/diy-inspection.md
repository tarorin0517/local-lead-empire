# 宇和島市の浄化槽・自分でできる日常点検チェックリスト

浄化槽は法律で定められた保守点検・清掃・法定検査が義務付けられていますが、日常の「目視確認」を管理者自身が行うことで、異常の早期発見が可能になります。本コラムでは宇和島市の環境特性（台風・リアス海岸・農薬使用）を踏まえた日常点検のポイントをチェックリスト形式で解説します。

## 毎月の日常点検チェックリスト

### 外観の確認

- [ ] マンホールのふたが正しく閉まっているか（ずれ・浮き上がりがないか）
- [ ] マンホール周辺に異常な臭いがないか
- [ ] マンホール周辺に水がにじみ出ていないか（槽のひび割れのサイン）
- [ ] ブロワー（送風機）の電源ランプが点いているか、異音がしていないか
- [ ] 放流先（側溝・水路）が詰まっていないか

### 放流水の確認

- [ ] 放流水に泡立ちや異色（茶色・黒色）がないか
- [ ] 放流水に強い臭いがないか
- [ ] 放流先の水が澄んでいるか

### 室内の確認

- [ ] 台所・洗面台・トイレの排水が正常に流れているか
- [ ] 排水口・便器から嫌な臭いが上がってきていないか

## 宇和島市特有の確認ポイント

### 台風・大雨後の確認（7〜10月）

宇和島市はリアス式海岸に面した地形のため、台風による増水・土砂崩れが浄化槽に影響することがあります。台風・大雨後は以下を必ず確認してください。

- [ ] マンホールのふたがずれていないか
- [ ] 周囲の土砂・落ち葉が放流先を塞いでいないか
- [ ] 浮力で槽体が浮き上がっていないか（地盤が緩い場所は特に注意）
- [ ] 浸水した形跡がないか

特に三間地区の山間部・津島の岬エリアでは土砂崩れ・増水が起きやすく、放流先が塞がれると逆流・臭い発生につながります。

### 農薬散布後の確認（春・秋）

吉田・三間のミカン農家では農薬散布時期（春の摘花剤・秋の着色促進剤）に、農薬が配管に誤って流入することがあります。農薬散布後は以下を確認してください。

- [ ] マンホール周辺から普段とは違う臭いがしていないか
- [ ] 放流水の色・泡立ちに変化がないか

農薬が流入すると槽内の微生物が死滅し、処理機能が急低下します。臭いの急変に気づいたら早めに業者に連絡してください。

### 養殖業・漁業世帯の確認（通年）

吉田・津島など漁業・養殖業が盛んなエリアでは、魚介類の処理後に有機物が多量に流れ込みやすい環境です。以下の点を日常的に確認してください。

- [ ] 魚の臭いとは異なる、腐敗臭・硫黄臭がしていないか
- [ ] 排水の流れが遅くなっていないか（詰まりのサイン）

## プロに連絡すべき症状

以下の症状が1つでもある場合は、自己判断せずに保守点検業者・清掃業者に連絡してください。

- マンホール周辺から強い腐卵臭（卵が腐った臭い）がする
- 放流水が茶色・黒色になっている
- マンホールのふたが浮き上がっている・ずれている
- ブロワーの電源が入っていない、または異音がする
- 台風・大雨後に浄化槽周辺が浸水した
- 農薬散布後に急に臭いが変わった
- 清掃から1年以上経過している

## まとめ

宇和島市では台風・農薬散布・養殖業特有の排水という地域特有のリスクがあります。毎月の目視確認で「臭い・色・流れ」の異常に早めに気づくことが、浄化槽を長く健全に保つコツです。
